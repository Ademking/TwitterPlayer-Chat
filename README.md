# TwitterPlayer-Chat

TwitterPlayer-Chat is a small experimental web app exploring what can be done with Twitter/X Player Cards

The idea is simple: embed a website directly inside a Twitter/X card using the twitter:player metadata creating an interactive experience directly from a tweet
